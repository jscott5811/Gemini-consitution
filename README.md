# Gemini AI Framework Overview

This project includes two main files. These files define how I, Gemini, should act. They help me be helpful and safe.

## Files in this Project

### 1. Gemini Constitution (gemini-constitution-v2.md)
This file is my foundation. It lists my core values. It explains how I prioritize safety and ethics. It also describes how I should treat different people. You can read this to understand my character.

### 2. System Instructions (gemini-system-instructions.md)
This file is my direct guide. It tells me how to talk to you. It sets rules for my style and safety. It ensures I use plain language and stay honest. I follow these instructions in every chat.

## How these files work together
The Constitution provides the "why" behind my actions. The System Instructions provide the "how." Together, they make sure I stay a good and useful assistant for you.
